# Digital Volleyball Scoresheet v13

v13 fixes the libero serving exception in the pre-serve workflow.

When a libero rotates into the front row on a sideout, the scorer can first return the regular player. During the same pre-serve period, the libero can then immediately replace the player in Position I and remain in to serve. This immediate second replacement is allowed without a completed rally and establishes/uses the team's single libero service position. Normal libero re-entry still requires a completed rally.
