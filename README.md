# Digital Volleyball Scoresheet Prototype v2

Static Vercel-ready prototype.

## Added in v2
- New starting lineup entry before every set (positions I–VI)
- L1 and L2 libero entry for each set/team
- Team serving first selection for each set
- Mandatory server verification before the opening serve and every change of service
- Explicit L1/L2 libero-serving selection, including the rotation player served for
- Warning when an unexpected server is entered
- Structured substitutions: Team, Player OUT, Player IN
- Event log and undo snapshots
- Browser local storage

This remains a prototype and is not yet certified as an official NCAA scoresheet replacement.
